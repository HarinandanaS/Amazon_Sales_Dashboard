# 🛒 Amazon Sales Dashboard

A professional **Amazon Sales Dashboard** built using **Power BI** and **Python** to analyze sales performance, profit, customer ratings, and regional trends.

---

## 📌 Project Overview

This dashboard provides valuable business insights through interactive visualizations. It helps analyze:

- 💰 Total Sales
- 📈 Total Profit
- 📦 Total Orders
- ⭐ Average Rating
- 📊 Profit Margin
- 🛍️ Sales by Category
- 💵 Profit by Category
- 🌍 Sales by Region
- 💳 Sales by Payment Method

## 🚀 Key Insights

- Electronics generated the highest sales.
- North region recorded the maximum sales.
- Credit Card was the most preferred payment method.
- Dashboard includes interactive slicers for Category, Region, and Payment Method.

## ▶️ How to Run

1. Clone the repository.
2. Open `Amazon_Sales_Dashboard.pbix` in Power BI Desktop.
3. Run the Python scripts if you want to recreate the analysis and charts.
